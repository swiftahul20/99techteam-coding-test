# 99TechTeam Coding Challenge

An interactive website to implement their code challenge as a coding test to fullfill job application as a Frontend Developer.

---

## Live Demo

https://99techteam-coding-test.vercel.app/

## Tech Stack

| Purpose   | Tool                                                                                                                              |
| --------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Framework | React + Vite                                                                                                                      |
| Styling   | [Tailwind CSS](https://tailwindcss.com/)                                                                                          |
| AI Tools  | Claude Code                                                                                                                       |
| Language  | JavaScript                                                                                                                        |
| API       | [Prices](https://interview.switcheo.com/prices.json) - [Icon](https://raw.githubusercontent.com/Switcheo/token-icons/main/tokens) |

---

## Installation & Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in your browser
http://localhost:5173
```

```bash
# Production build
npm run build
npm run start
```
